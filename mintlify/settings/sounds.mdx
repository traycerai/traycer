**Sounds** decides how this app alerts you. It sits in the **Application** group of [Settings](/settings), so one set of chimes applies to notifications from every host.

Which events create a notification in the first place is set per host, in Host › [Notifications](/settings/notifications). For what notifications are and where they appear, see [Notifications](/concepts/notifications).

## Chimes

Choose a sound for each kind of notification. Choosing a sound plays it, so you can try each one.

| Notification | Covers | Default sound |
| --- | --- | --- |
| **Needs action** | Approvals and interviews. | Orbit |
| **Failure** | Errored turns, stalls, crashes, and rate limits. | Rift |
| **Done** | Completed or intentionally stopped turns. | Prism |
| **Info** | Sharing, comments, access changes, and other informational notifications. | Ember |

The sounds are Classic, Prism, Ripple, Ember, Orbit, Rift, Coin, Bloop, Cuckoo, Ta-da and Beacon. Choose **None** to keep that kind of notification silent.

## System

**OS notifications** (desktop app): banners, badges and delivery are managed by your operating system. Click **Open Settings** to open your OS notification settings for Traycer.

## This Phone

**Push notifications** (mobile app) shows whether this phone can receive push notifications when an agent needs you:

- If you haven't been asked yet, tap **Enable**.
- If they are turned off for Traycer, tap **Open Settings** to turn them back on in the phone's Settings app. The phone only asks once, so this is the way back after you declined.
- When they are on, the row reads **On**.

## Events

**Notification events** chooses which events alert you, for the host selected in Settings. Click **Open Host Notifications** to go to Host › [Notifications](/settings/notifications).
