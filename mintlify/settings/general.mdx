---
title: "General"
description: "Configure general Traycer Desktop behavior."
---

General settings cover app-level behavior that is not specific to a provider, terminal, or worktree.

## Options

| Setting | What it changes |
|---|---|
| **Notify on agent turn completion** | Sends a notification when an agent turn finishes. |
| **Prevent sleep while running** | Keeps the machine awake while Traycer work is active. |
| **Voice settings** | Controls voice input behavior used by agent prompts. |
| **Local snapshots** | Manages local snapshot data. |
| **Clear local snapshots** | Removes stored local snapshots. |
| **Data migration** | Retries the local-to-cloud data migration when available. |

Use General for broad app behavior. Provider setup, shell configuration, and host management each have their own settings pages.
