Keybindings are local keyboard shortcuts. They are a UI preference stored on this device, not shared Task content.

This page covers four kinds of shortcut:

- [Shortcuts you can rebind](#default-shortcuts) in **Settings → Keybindings**.
- [Number shortcuts](#number-shortcuts), which are fixed.
- The [global Summon shortcut](#global-shortcut), which works even when Traycer is in the background.
- [Menu shortcuts](#menu-shortcuts), which belong to the app menu and are fixed.

Linux uses the same defaults as Windows.

## Customize Shortcuts

Open **Settings → Keybindings**. Every action is in one list, followed by the **Sub-leader** section and, in the desktop app, **Global shortcuts**.

<Steps>
  <Step title="Find the command">
    Locate the action you want to change in the list.
  </Step>
  <Step title="Capture a new shortcut">
    Click the shortcut chord chip. When it reads **Press chord…**, press the key combination you want to assign. Press **Esc**, or click away from the chip, to cancel.
  </Step>
  <Step title="Clear or reset (optional)">
    Press **Backspace** while capturing to unbind an action. The chip then reads **Unbound**. Click **Reset all to defaults** at the bottom of the page to restore every shortcut at once, including the Summon shortcut.
  </Step>
</Steps>

Number shortcuts, such as **Switch tab by number**, appear in the list with their keys but can't be rebound. See [Number Shortcuts](#number-shortcuts).

### Conflicts

Traycer checks each new chord as you capture it:

| Situation | What happens |
|---|---|
| Another action already uses the chord | The chord is not saved, and a message under the chip says it is already bound. Pick a different chord, or unbind the other action first. |
| The chord is the Summon shortcut | The chord is not saved while Summon is enabled. |
| The chord is a common system shortcut that no other action uses, such as <kbd>Cmd</kbd> + <kbd>P</kbd> or <kbd>Cmd</kbd> + <kbd>F</kbd> | The chord is saved, with a warning that it overrides the system shortcut. |
| A focused browser tile keeps the chord for itself | The chord is saved, with a warning that it won't fire while a browser tile has focus. |
| On macOS, **Voice input** or **Toggle model picker** gets a <kbd>Cmd</kbd> chord | The chord is not saved. These two actions need <kbd>Control</kbd>, because macOS can't detect when <kbd>Cmd</kbd> is released. |

### Shortcuts In A Focused Terminal

On Windows and Linux, many <kbd>Ctrl</kbd> chords mean something to the shell. While a terminal tile has focus, these default shortcuts go to the terminal instead of Traycer: **New task**, **New tab**, **Close tab**, **Close other tabs**, **Next tab**, **Previous tab**, **Add current tab to new split view**, **Split group horizontally**, **Split group to the right**, **Focus active tab editor**, **Toggle left panel**, **Open history**, **Toggle terminal panel**, **Maximize terminal panel**, **Drafts**, and <kbd>Ctrl</kbd> + <kbd>K</kbd> for the command palette.

Use <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> to open the command palette from a terminal. A shortcut you rebind yourself always goes to Traycer. On macOS, <kbd>Cmd</kbd> shortcuts always go to Traycer.

## Default Shortcuts

These shortcuts can be rebound. An action marked "Unbound" has no default shortcut: give it one in Settings, or run it from the command palette.

### Tasks

Each tab in the header strip holds a Task, a draft, History, or Settings.

| Command | macOS | Windows / Linux | What it does |
|---|---|---|---|
| New task | <kbd>Cmd</kbd> + <kbd>N</kbd> | <kbd>Ctrl</kbd> + <kbd>N</kbd> | Open the landing page to start a new Task. |
| Duplicate tab | <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>K</kbd> | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>K</kbd> | Duplicate the active Task tab and its tiling layout. |
| Next Task tab | <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>]</kbd> | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>]</kbd> | Activate the next tab in the header strip. |
| Previous Task tab | <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>[</kbd> | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>[</kbd> | Activate the previous tab in the header strip. |
| Close active tab | <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>W</kbd> | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>W</kbd> | Close the active header tab, whatever it holds: a Task, a draft, History, or Settings. |

**Split group horizontally** (<kbd>Cmd</kbd> + <kbd>D</kbd>) and **Split group to the right** (<kbd>Cmd</kbd> + <kbd>&#92;</kbd>) do the same thing: both add an empty group on the right and focus it. You can rebind either one.
</Note>

## Number Shortcuts

Number shortcuts are leader chords: hold the modifier and press a digit. They are shown in **Settings → Keybindings** for reference and can't be rebound.

| Command | macOS | Windows / Linux | What it does |
|---|---|---|---|
| Switch tab by number | <kbd>Cmd</kbd> + <kbd>1</kbd>–<kbd>9</kbd> | <kbd>Ctrl</kbd> + <kbd>1</kbd>–<kbd>9</kbd> | Jump to that tab in the active group, or in the start page's panel. |
| Switch model provider by number | <kbd>Cmd</kbd> + digit | <kbd>Ctrl</kbd> + digit | While the model picker is open, switch the provider you are browsing. |
| Change model settings by number | <kbd>Opt</kbd> + <kbd>1</kbd>–<kbd>9</kbd>, <kbd>Opt</kbd> + <kbd>0</kbd> | <kbd>Alt</kbd> + <kbd>1</kbd>–<kbd>9</kbd>, <kbd>Alt</kbd> + <kbd>0</kbd> | While the model picker is open, 1–9 set the thinking effort and 0 turns **Fast** on or off, where the model offers it. |
| Switch profile by number | <kbd>Cmd</kbd> + <kbd>Shift</kbd> + digit | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + digit | While the model picker is open and the provider has two or more profiles, switch to that profile. |

### Sub-leader

The **Sub-leader** section of **Settings → Keybindings** lists the two number shortcuts that use <kbd>Opt</kbd> / <kbd>Alt</kbd> rather than the primary leader. It is a reference, not a setting.

| Command | macOS | Windows / Linux | What it does |
|---|---|---|---|
| Switch task by number | <kbd>Opt</kbd> + number | <kbd>Alt</kbd> + number | Jump to that header tab. For tab 10 and above, keep holding the modifier and type both digits. |
| Switch settings section by number | <kbd>Opt</kbd> + <kbd>1</kbd>–<kbd>9</kbd>, <kbd>Opt</kbd> + <kbd>0</kbd> | <kbd>Alt</kbd> + <kbd>1</kbd>–<kbd>9</kbd>, <kbd>Alt</kbd> + <kbd>0</kbd> | In Settings, jump to that sidebar section. 0 is the tenth section; later sections have no number shortcut. |

## Global Shortcut

**Summon Traycer** shows and focuses Traycer from anywhere, even when another app is in front. It is under **Global shortcuts** in **Settings → Keybindings**, in the desktop app only.

| Command | macOS | Windows / Linux |
|---|---|---|
| Summon Traycer | <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>Space</kbd> | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Space</kbd> |

- It is on by default. Turn it off with the **Enable summon shortcut** switch.
- Rebind it with its chord chip, like any other shortcut. A global shortcut needs at least one modifier key. Pressing **Backspace** while capturing restores the default chord instead of unbinding it.
- If another application already holds the chord, the row shows "In use by another application." Pick a different chord.
- While Summon is enabled, no other action can use its chord.

| **Edit → Find Previous** | <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>G</kbd> | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>G</kbd> |

## Command Palette

Open the command palette, type part of a command name, and select the matching action. Actions with no default shortcut, such as the split view actions and **Toggle status bar**, can still be run from the palette. See [Search and navigation](/concepts/search-and-navigation).
