---
title: "Appearance"
description: "Configure Traycer Desktop theme and visual preferences."
---

Appearance settings change how Traycer Desktop looks locally.

## Options

| Setting | What it changes |
|---|---|
| **Theme** | Uses system, light, or dark appearance. |
| **Preset** | Applies a visual preset. |
| **Terminal preview** | Controls terminal preview behavior. |
| **Use pointer cursors** | Changes whether interactive controls use pointer cursors. |
| **Artifact icon colors** | Shows artifact icons by type color, or disables type coloring. |
| **UI font size** | Changes app UI text size. |
| **Code font size** | Changes code and editor text size. |

Appearance preferences are local UI preferences. They do not change Task content or shared artifacts.
