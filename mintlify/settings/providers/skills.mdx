Open **Settings → Providers**, select a provider, and open **Skills**. Skills hold reusable instructions you can invoke from chat.

## Create A Skill

1. Click **Add skill**.
2. Enter its **Name**, **Description**, and Markdown **Instructions**.
3. Choose who can use it under **Available to**. **Every provider** creates a shared skill.
4. Click **Create skill**. Shared skills appear in the list with a **Shared** badge.

Invoke a skill by its slash command in chat, such as `/release-notes` for a skill named `release-notes`.

**Skills** and **Plugins** are separate tabs. Create named Markdown instructions in **Skills**; use **Plugins** to install from a plugin source string.
