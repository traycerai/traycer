<Update label="v1.3.0">
A browser inside Traycer, the mobile app, and importing your Claude Code and Codex sessions.

- **In-app browser** — browse the web without leaving Traycer, and let agents drive a browser session of their own. Sign-ins are kept between sessions, can be imported from another browser on this machine, and carry over when an agent opens the same site.
- **Mobile app** — follow your Tasks, agents, artifacts, terminals, and comments from your phone. Link it from **Settings › Link mobile app** by scanning a code.
- **Session import** — bring existing Claude Code and Codex sessions into Traycer, from Settings or as the last step of the tour.
- **Side chats** — type `/btw` or `/side` with a question to ask it in a fork, leaving the running agent undisturbed.
- **Communication Graph** — an office view of the agents in a Task, search, and message cards that jump between the sent and received sides of an exchange.
- **Sweep** — review worktrees in two steps before anything is deleted, let a confirmed sweep run in the background, and see worktree counts per Host. Busy worktrees can be force-deleted after Traycer shows what will be stopped.
- **Long chats** — very long transcripts open quickly and load older messages as you scroll.
- **Previews** — open PDFs from the workspace and git diff.
- **Artifacts** — send selected artifact text to a chat, and search artifacts by path.
- **Notifications** — choose a notification chime and preview it. The notification center shortcut is now ⌘⇧B / Ctrl+Shift+B, since ⌘⇧N already opens a new window.
- **Providers** — the Reasonix coding agent is now available, harnesses are enabled with a plain toggle, provider packs can be checked for updates, and you control which accounts an agent may pick. Each turn shows which environment credential signed it in.
- **Interviews** — review the questions an agent asked and how you answered them.
- **Host updates** — updates show their progress, wait rather than interrupting busy work, and an explicitly chosen older Host is kept instead of being upgraded again. Auto-update failures on Windows and Linux are fixed.
- **Remote hosts** — available on every plan.
- **Tabs** — drag tabs the way Chrome does, and tear a draft off into its own tab.
- **Keyboard** — Ctrl shortcuts reach a focused terminal on Windows and Linux.
- **Open in** — Finder and VSCodium are available as open targets, and sidebar menus can copy an item's ID.
- **Fixes** — the clock drifting on your machine no longer disconnects streams; steered messages stay where you sent them; generated titles stick in history; and the renderer uses less memory with many Tasks open.
</Update>

<Update label="v1.2.0">
Remote hosts, chats backed up to the cloud, and usage dashboards.

- **Remote hosts** — connect a Host running on another machine and run agents there. Choose the Host from the composer, browse its folders, fork a chat onto it, and filter History by Host. See [Remote hosts](/concepts/hosts/remote-hosts).
- **Chat backup and sharing** — chats live on your Host with a backup in the cloud, shown in the chat header. Choose who can see each chat.
- **Communication Graph** — watch the agents in a Task message each other.
- **Usage dashboards** — cost, tokens, and tool calls by harness, model, or chat, exported as an image to share.
- **Shells** — agents can start long-running commands and get notified when they print or exit. Each one appears as a card you can open.
- **Providers** — a rebuilt Providers pane with search and filters; pick, keep, or pause each provider's CLI version; connect model providers through OpenCode; sign in to Copilot from a terminal. Hugging Face is now available, with usage limits shown for Cursor and OpenCode Go.
- **Skills, MCP servers, and plugins** — manage them from Settings, including importing skills and sharing one copy across providers.
- **Git diff** — edit files directly in the diff, preview images, and open large PR diffs faster.
- **Composer** — mention GitHub pull requests and issues, and reuse recent folders.
- **Fork an agent** — fork an agent from the app or with `traycer agent fork`.
- **Terminals** — terminals persist on the Host, and agents can read a terminal's output.
- **Navigation** — minimaps for artifact headings and chats, new shortcuts for moving around and opening resources, and ⌘Enter / Ctrl+Enter to confirm the primary action.
- **Notifications** — read state syncs across your devices, with a shortcut to open the notification center.
- **Devices & Sessions** — see and manage where you are signed in.
- **Host** — restart the Host from the menu or tray, force a stop or restart when work is stuck, and scope the resource monitor to one Host.
- **Worktrees** — set a branch prefix per repository.
- **Fixes** — the app no longer grows to several gigabytes of memory in long sessions; streaming replies render smoothly; and archived chats are marked and can be filtered.
</Update>

<Update label="v1.1.10">
The per-agent Epic / Regular mode control is gone. Tasks and artifacts remain.

- **Per-agent mode** — the composer, settings, and `traycer agent create` no longer offer Epic Mode. That setting belonged to the agent, not to the Task. A Task is still the container for agents, files, git diff, and artifacts.
- **Artifact workflow** — [Artifact workflow](/concepts/artifact-workflow) covers the remaining planning skills, typical order, and that Traycer does not guarantee an automatic skill pipeline. Picking a skill with `$` or `/` is a reliable way to run one; it is not a new requirement that every artifact be requested by hand.
</Update>

<Update label="v1.1.9">
Two tabs side by side, search across artifacts and workspaces, and the Oh My Pi coding agent.

- **Split the window** — put any two tabs side by side: a Task next to History, or Settings next to a draft. Each side scrolls on its own, and the divider can be dragged or resized from the keyboard. Drag a tab to the edge of the window and hold, or pick one from the list.
- **Search** — search artifacts and workspaces, jump to nested panes by path, and find past Tasks by branch, folder, or PR number.
- **Oh My Pi** — the Oh My Pi coding agent is now available.
- **Agent roles** — give an agent a role, from the app or the CLI.
- **Steer a running agent** — press ⌘Enter to send a message to a coding agent mid-turn instead of waiting for it to finish; Enter still queues it for afterwards. Not every coding agent supports this, and it can be turned off in Settings.
- **Sidebar** — chat rows show a second line of detail and a leading icon, and archiving is easier to reach.
- **Worktrees** — clear out a Task's finished worktrees from History or the sidebar, one at a time or several at once, and choose your own branch prefix.
- **Context usage** — compact a conversation straight from the context chip.
- **Grok profiles** — connect several Grok accounts and choose which one each agent uses, with isolated sessions and usage limits per account.
- **Workspace files** — the file list keeps up as files change, and artifacts tell you once they have finished syncing.
- **Notifications** — an agent that stops because it ran out of context, or because its request was refused, now tells you which. Clicking a notification opens the window holding that chat, and terminal agents get their own indicators.
- **Installing and updating** — a failed install or update offers a way forward instead of leaving you stuck. On macOS, Traycer recovers from a failed background-service registration, and no longer runs slowed down in the background.
- **Windows** — fixed the menu bar, window controls at non-default zoom levels, and theme switching. Environment variable overrides keep their original capitalization.
- **Fixes** — drafts clear everywhere once sent; sign-in completes as soon as you approve it in the browser; updates ask once rather than twice before restarting; a terminal agent that fails to launch explains why; Worktrees keeps your selection as you move around Settings; adding an image no longer moves your cursor; a failed compaction is no longer marked as done; numbered lists keep their starting number; mentions accept spaces; the composer keeps focus when you switch panes; buttons work again after your machine wakes; and a provider being rechecked keeps its models on screen.
</Update>

<Update label="v1.0.0">
First public release of Traycer Desktop — the native app for delegating engineering work to coding agents in a local-first workspace. It bundles the Traycer CLI and provisions the local Host automatically, so there is nothing else to install.

- **Tasks** — long-lived, repository-bound workspaces where you plan, chat, run terminal agents, review diffs, and keep history. Everything is stored locally.
- **Coding agents, your choice** — connect Claude (Claude Code), OpenAI Codex, Cursor, OpenCode, or Traycer Inference and switch per conversation. Set reasoning effort and an optional Fast tier on supported models.
- **Chats** — persistent conversations, run several in parallel, per-conversation change tracking, auto-saved drafts.
- **Terminal agents** — terminal-based agents on a full xterm terminal; sessions persist across host restarts.
- **Plan and review** — side-by-side git diffs, file viewing, and line-level comment threads.
- **Worktrees** — isolated git worktrees keep your main checkout clean.
- **Multiple machines** — choose the machine a chat or terminal runs on; each tab stays bound to its host for life.
- **Native desktop** — system tray, native notifications, command palette, customizable keybindings, multiple windows, the `traycer://` deep-link scheme, and light/dark/system themes.
- **Sign in once** — browser-based (PKCE) sign-in, shared with the bundled CLI.
- **Background updates** — downloaded in the background and installed on quit, using signed release artifacts.
- **Platforms** — macOS 12+ (Apple Silicon and Intel, signed and notarized) and 64-bit Linux.
</Update>
