This page is the compatibility reference for Traycer's coding agents and model selection.

For the agent surface itself, including composer controls, permissions, attachments, voice input, and per-turn behavior, see [Agents](/panels/agents).

<Info>
  - **Chat** and **Terminal** say which [interface](/concepts/terminal-agents-vs-terminals) the coding agent can back. A coding agent that uses a CLI behind its Chat integration is not automatically available on the Terminal interface.
  - **Fast mode** appears only when the selected model offers a fast tier.
  - **Profiles** means you can add more than one account for that coding agent. See [Managed Profiles](/settings/providers#managed-profiles).
  - **Steer mid-turn** means a message can go into the running turn. For the others, a steered message waits for the next turn. See [Message queue](/panels/agents/message-queue).
  - **Permission modes** lists which of the four [permission modes](/panels/agents#permissions) the coding agent accepts. The ones it can't honor are disabled in the composer's permission picker.
</Info>

- **Turned on.** Claude Code and Codex start enabled; Traycer Inference is opt-in. Other providers can turn on at host startup after credential verification, unless you have already chosen their setting. See [Turn A Provider On Or Off](/settings/providers#turn-a-provider-on-or-off).
- **CLI.** Traycer downloads and updates the CLIs it manages; see [CLI Binary And Arguments](/settings/providers#cli-binary-and-arguments). Install the Amp, Hermes Agent, and Command Code CLIs yourself. Command Code installs with `npm i -g command-code`; its command is `cmd`, or `cmdc` on Windows. Antigravity has no Intel Mac build, so on an Intel Mac install the Antigravity IDE to get its agent server.
- **Settings tabs.** Every provider also has **CLI & Args**, **Env**, and **Permissions**. What each tab holds is in [Provider Tabs](/settings/providers#provider-tabs).

## Models

Traycer loads models from the selected coding agent and provider profile at runtime. The list can vary with your installed CLI version, account, provider configuration, and model access, so these docs don't keep a fixed model list.

In the composer's model picker:

- Choose a coding agent in the rail, then a model. ⌘1–9 / Ctrl+1–9 switches the coding agent while the picker is open. ↑/↓, Home/End, Enter, and Esc also work.
- A coding agent with two or more profiles shows a profile dropdown. ⌘⇧1–9 / Ctrl+Shift+1–9 switches profile.
- Thinking effort appears only when the selected model supports reasoning levels. ⌥1–9 / Alt+1–9 sets it.
- Fast mode appears only when the selected Claude Code, Codex, or Cursor model has a fast tier. ⌥0 / Alt+0 toggles it.
- Models that are being retired carry a **Deprecated** badge.
- **Refresh providers & models** reloads the list, and **Provider CLI settings** opens [Providers](/settings/providers).
- ⌃⌥M / Alt+Shift+M opens and closes the picker.

Only coding agents that are turned on appear in the picker.

- **Needs sign-in.** A coding agent that is signed out or missing its API key stays in the rail, dimmed. Select it to see **Not authenticated** and the fix: **Sign in from a terminal**, **Set up in terminal**, or **Add API key**, depending on the agent.
- **Still downloading.** While Traycer downloads a coding agent's CLI, its rail entry shows the progress, for example "Preparing Grok… 40%". If Traycer has no other copy of that CLI to run, you can pick it once the download finishes.

**Traycer Inference** uses Traycer credits. Other coding agents use their own account, API, or provider billing; see [Pricing](/account/pricing).

When a coding agent hits a usage limit, Traycer can offer another profile or switch models for you. See [Usage limits and model routing](/agents-and-models/usage-limits-and-routing) and [Model routing](/settings/model-routing).

## Provider Setup

Configure credentials, environment variables, CLI binaries, profiles, and default Terminal interface CLI arguments in [Settings > Providers](/settings/providers).

Claude Code, Codex, Grok, and Antigravity support multiple managed profiles. What a profile shares with your default login, and how Grok keeps its profiles separate, is in [Managed Profiles](/settings/providers#managed-profiles).

To switch accounts for the next turn, open the model picker and choose a profile from the profile dropdown.
