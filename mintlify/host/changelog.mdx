<Update label="v1.3.1">
* **Cursor** — Composer no longer always runs in fast mode; the fast setting is applied per run.
</Update>

<Update label="v1.3.0">
Agent-controlled browsers, session import, and much faster Tasks.

* **Browser sessions** — agents can open and drive browser sessions, with sign-ins stored encrypted and carried across Hosts.
* **Session import** — bring Claude Code, Codex, and OpenCode sessions into Traycer.
* **Mobile app** — the Host serves the Traycer mobile app.
* **Faster Tasks** — Tasks open from local data in a fraction of the time, long chats load in windows, and memory use is reported accurately.
* **Comments as files** — agents read comment threads as files beside each artifact and resolve them by editing their status.
* **Worktrees** — deleting a worktree first stops whatever is using it, sweeps ask for consent before tearing anything down, and deletion rows say why they failed.
* **Providers** — the Reasonix coding agent is now available; OpenCode reaches parity with Claude; Copilot, Qwen, Grok, and the OpenCode family can be steered mid-turn; Grok gets background work and managed profiles; and sign-in terminals launch the CLI for Qwen, Droid, OMP, and OpenCode.
* **Harness enablement** — harnesses are enabled once you are signed in, then stay on or off as you set them.
* **Shells** — choose per command whether it relaunches when the Host restarts.
* **Updates** — updates are tracked through to completion, and explicit downgrades are supported.
* **Reliability** — fixes for artifacts lost after a storage replacement, a slow git process taking down a Task, and a Windows Host crash.
</Update>

<Update label="v1.2.0">
Remote hosts, chats backed up to the cloud, and usage analytics.

* **Remote hosts** — a Host can run on another machine and be reached through Traycer's relay.
* **Chat sync** — chats live on the Host, are backed up to the cloud, sync across Hosts, and can be shared or kept private.
* **Communication Graph** — messages between agents are recorded and streamed for each Task.
* **Usage analytics** — cost, tokens, and tool calls are captured and priced per turn.
* **Shells** — agents can run long-running commands that notify them, including in the middle of a turn.
* **Providers** — Hugging Face and OpenCode model providers are available, provider CLI versions can be chosen, provider CLIs are downloaded on demand, and Cursor and OpenCode Go usage limits are reported.
* **Terminals** — terminals are owned by the Host and persist across windows and Hosts. Agents can read a terminal's output.
* **Agents** — fork an agent, stop its whole runtime rather than just the turn, and create agents without a folder.
* **Skills** — imported skills are stored once and shared across providers.
* **Git** — edit files in place from the diff, and read GitHub pull requests and issues for mentions.
* **Worktrees** — branch prefixes can be set per repository, and recent workspace folders are remembered.
* **Fixes** — Claude profiles no longer sign themselves out, idle Hosts stay quiet, and restart checks ignore idle terminals.
</Update>

<Update label="v1.1.10">
Epic Mode removed, and a steadier Host under load.

* **Epic Mode removed** — agents no longer carry an Epic or Regular mode, and the Traycer system prompt is shorter.
* **Agents** — archive an agent from another agent, stop an agent with `traycer_stop_agent`, and working agents can no longer be archived.
* **Agent-to-agent** — agents created by other agents run with full access.
* **Pull requests** — the PR view is back, fetches each PR once per Host, and finds PRs from the branch actually checked out.
* **Terminals** — terminal titles show the live working directory.
* **Git status** — a bounded file watcher on Linux, with its health reported to the app.
* **Grok** — change reasoning effort mid-session.
* **Fixes** — Claude sessions survive pressing Stop during background work, Copilot starts on the default model, Pi reports its real failure reason, model catalogs no longer flood the Host with requests, and Windows provider CLIs launch directly.
</Update>

<Update label="v1.1.9">
The Oh My Pi coding agent, agent roles, and installs that recover instead of leaving you stuck.

* **Oh My Pi** — the Oh My Pi coding agent is now available.
* **Agent roles** — an agent can carry a role.
* **Steer a running agent** — supported coding agents can take a message while their turn is still running. Others queue it for afterwards.
* **Grok profiles** — use several Grok accounts with isolated sessions and usage limits.
* **Search** — artifacts and workspaces can be searched within a chosen scope, and a workspace's file list keeps up as files change.
* **Artifacts** — the Host reports when artifacts have finished syncing, rather than assuming they have.
* **Notifications** — an agent that stops because it ran out of context, or because its request was refused, now reports which. Terminal agents get their own indicators, and notifications resume after a terminal closes.
* **Archiving** — chats can be archived.
* **Install and update** — a failure now offers a way forward instead of leaving you stuck. On macOS, the Host no longer runs slowed down in the background.
</Update>

<Update label="v1.0.0">
First public release of the Traycer Host — the local runtime that powers Traycer. It runs the coding agents, terminals, and Tasks behind Traycer Desktop, entirely on your machine. You do not install the Host directly; the Traycer CLI downloads, verifies, and supervises it for you.

* **Runs agents locally** — executes your chosen coding agents directly on the repositories you are working in.
* **Local storage** — stores Tasks, conversations, plans, and history in a local SQLite database.
* **Terminals, files, and worktrees** — manages terminals, files, and git worktrees, and exposes a versioned protocol that Traycer Desktop connects to.
* **Managed service** — registers with your OS service manager (launchd on macOS, systemd user on Linux), starting with your session and supervised automatically.
* **Agent backends** — Claude (Claude Code), OpenAI Codex (with reasoning depth and optional Fast tier), Cursor, OpenCode, and Traycer Inference, selectable per Task.
* **Skills** — ships Traycer's versioned, integrity-checked workflows for brief, plan, breakdown, execution, and review.
* **Privacy** — does not log secrets or source code.
* **Platforms** — macOS (Apple Silicon and Intel) and Linux (x64), delivered as a signed single-file runtime with no separate Node or Bun install. Builds are verified by SHA-256 checksum and minisign signature before installation.
</Update>
