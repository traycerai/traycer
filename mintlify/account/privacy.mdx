This page covers the data Traycer Desktop sends for product analytics and crash reports, and the **Privacy Mode** setting. For the full terms, read the [Privacy Policy](https://traycer.ai/privacy-policy).

## Product Analytics

Traycer Desktop sends product analytics events to PostHog so the team can see which features are used and where they break.

- Events are tied to your Traycer account ID and email address.
- PostHog's automatic click capture, page-view capture, session recording and error capture are turned off.
- URL properties are removed from every event before it is sent.

The host on each of your machines also sends a small set of events to PostHog, such as prompt-cache health, Auto mode outcomes and host performance. These are tied to your account ID.

There is no setting to turn product analytics off.

## Crash and Error Reports

The desktop app and the host send crash and error reports to Sentry so the team can fix them. There is no setting to turn these off either.

## Privacy Mode

**Privacy Mode** hides your prompt text in Traycer's usage logs. Turn it on or off with the **Privacy Mode** switch under **Settings → Privacy Settings** in the [web dashboard](https://platform.traycer.ai).

Privacy Mode is a per-user setting, and it is off for a new account until you turn it on. Teams have no separate privacy control: for usage billed to a team, prompt text is always hidden in usage logs.
