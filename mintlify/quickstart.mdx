This guide gets you from a fresh Traycer install to one useful coding-agent interaction. If you have not installed Traycer yet, start with [Install](/install).

<Note>
  This is the Desktop path. If you are using the IDE extension, use the [IDE
  Extension docs](/extension).
</Note>

## Before You Start

You need:

- Traycer installed.
- A coding agent you can use, such as Claude Code or Codex with your own account, or the Traycer provider, which uses Traycer credits. See [Agents & Models](/agents-and-models/coding-agents).
- Optionally, a local code folder for Traycer to work in.

## First Run

<Steps>
  <Step title="Sign in">
    Open Traycer and click **Sign in** on the **Welcome to Traycer** screen. You approve the sign-in in your browser. See [Sign In](/account/sign-in).
  </Step>
  <Step title="Finish onboarding">
    A short onboarding lets you choose your coding agents and import your existing Claude Code, Codex, and OpenCode chats. See [First run and importing](/first-run).
  </Step>
  <Step title="Pick a folder (optional)">
    On the start page, click **Add folder** to choose the project Traycer should work in, then choose where the agent runs: **Local**, a **New worktree**, or an **Existing worktree**. See [Worktrees](/concepts/worktrees). You can also start without a folder.
  </Step>
  <Step title="Send your first prompt">
    <Warning>
      New conversations start in **Full access**: the agent runs commands and edits files without asking. To be asked first, pick another mode in the composer's permission picker before you send, or change the default in Settings › Permissions › Modes › **New conversations start in**. See [Permissions](/settings/permissions).
    </Warning>

    Pick a coding agent, model and permission mode, describe a small, concrete change or investigation, and press **Enter**. Sending the prompt creates the Task and its first agent together, and the agent starts working.
  </Step>
  <Step title="Review the result">
    Use the [File Tree](/panels/file-tree) and [Git Diff](/panels/git-diff) panels inside the Task to inspect what changed. To roll back a turn's changes, see [Undo a turn](/panels/agents/undo-a-turn).
  </Step>
</Steps>

## What You Just Used

| Thing                | What it means                                           |
| -------------------- | ------------------------------------------------------- |
| **Workspace folder** | The local code folder Traycer is working against.       |
| **Task**             | The top-level container for this work.                  |
| **Agent**            | A coding-agent session inside the Task.                 |
| **Artifact**         | A durable spec, ticket, story, or review inside a Task. |
