HTML artifacts are interactive pages saved in a Task: reports, charts, comparisons, plans, and explainers. Unlike a passage in chat, the page remains in the [Artifacts](/panels/artifacts) panel for later use and revision.

## Create and Open a Page

Ask an agent for an HTML artifact. For example:

> Create an interactive HTML report comparing the approaches, with a table of trade-offs and expandable details.

Open the result from **Artifacts**, or ask the agent to show it inline in chat. An inline preview's **Expand** control opens it in its own panel. If the preview is current, the panel opens on **Latest** and follows later saves. An older preview opens its captured version instead. Type **@** and choose it from **Artifacts** when asking for changes.

HTML artifacts are folders with an `index.html` file and supporting styles, scripts, images, or data. You do not have to assemble these yourself: describe the result you want to the agent.

## Use and Review the Page

Buttons, filters, tabs, and other page interactions can work directly in the preview. Links to websites ask for confirmation before opening outside Traycer. Page content runs separately from the app; it does not have direct access to your files or signed-in session. Interactions can use online resources, so a downloaded page may still need an internet connection.

To request a targeted change, open the latest version and turn on **Comments**. Select an element or text to leave a thread, or use **Send to chat** to attach the selection to an existing agent chat's draft. Send the message when you're ready. While comments are on, you can still scroll the page, but its buttons and links don't respond. Turn comments off to use the page normally again. Turning comments on or off keeps the page loaded, so its scroll position, zoom and state stay put. See [Comments](/panels/comments).

The page's controls sit in a small strip in its top corner, and the page starts below them. Use **−** and **+** to zoom, and **More actions** for **Actual size** and **Download ZIP**. An artifact with more than one page also shows **Back** and **Home** to move between its pages.

## Versions and Downloads

Use the version button in the page's controls to preview saved versions. It reads **Latest** on the current page and shows the version you're viewing on an older one, such as **v1 of 3**. Choose **Older versions** to go further back, and **Latest** to return to the current page. Selecting a version does not replace the live artifact. Comments attach to the latest page, not a historical preview, so **Comments** is greyed out on an older version.

**Download ZIP**, in **More actions**, saves the version you're viewing, including its supporting files. Extract the ZIP to inspect or reuse the page and its files outside Traycer. ZIP downloads support up to 64 MB of files. This is a page download, not a PDF or screenshot.

## Interactive Apps in Chat

An agent can also display an interactive app supplied by a connected MCP server directly in chat. These **MCP Apps** are different from saved HTML artifacts: they belong to the tool response that produced them. Use **Open full screen** to give an app more room, then **Exit full screen** or Esc to return to chat.

When an app needs approval for a tool action, review the request before approving it. App downloads also ask for confirmation. A tool response is not automatically a saved artifact; ask the agent to create a separate deliverable if you need one in **Artifacts**.
