A `wireframe` code block in an artifact renders a self-contained HTML document as a live preview. Ask an agent to include a wireframe when you want to inspect a proposed screen or layout.

## Inspect A Preview

Hover the preview to reveal its controls. **Fullscreen** opens it in the **UI Preview** dialog. **Copy HTML** copies the preview's HTML so you can reuse or inspect it. The inline preview also has a resize grip.
