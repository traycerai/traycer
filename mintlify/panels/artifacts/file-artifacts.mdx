title: "File artifacts"
description: "Preview and download deliverables shared with a Task."
---

File artifacts are deliverables saved with a Task, such as PDFs, Word documents, images, text files, and other outputs. They appear in [Artifacts](/panels/artifacts), alongside documents, HTML pages, and canvases.

## Create and Open a File

Ask an agent to save a deliverable in the Task's artifacts folder. A standalone file there becomes a file artifact. For example:

> Create a PDF summary and save it as a Task artifact so everyone can download it.

Click the file in **Artifacts** to open it. PDFs, Word documents, images, and supported text files have in-app previews. Other formats offer a download so you can open them in a suitable app. Large text previews may be shortened; download the file for the complete content.

A file inside an HTML or canvas artifact's supporting files belongs to that artifact. Ask the agent to save a deliverable as a separate file artifact if you want it to have its own row.

## Share Context and Request Changes

Type **@** in an agent message, choose **Artifacts**, and select the file. Ask the agent to inspect it, revise it, or create another format. A preview is not a document editor: use an agent to update the original deliverable.

Task artifacts are separate from files in your repository. Sharing a Task lets collaborators access its published artifacts; it does not give them access to browse your workspace. See [File Tree](/panels/file-tree).

## Download

Use **Download** in the open file's toolbar to save the original file to your device. Downloading a file preserves its format; it does not convert it to Markdown or PDF.
