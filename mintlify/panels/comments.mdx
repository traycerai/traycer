The **Comments** panel shows comment threads for the active artifact.

It is contextual: if there is no active artifact with comments available, the panel does not need to take space.

## Comment Threads

Comments are anchored to artifact text. Use them for questions, review notes, decisions, and follow-ups that belong to a specific artifact.

Typical flow:

1. Select text in an artifact.
2. Add a comment.
3. Continue the thread.
4. Resolve the thread when the discussion is done.

Resolved threads leave the **Open** list. Switch to **Resolved** to find them again.

## Where Comments Appear

Comments are part of artifact collaboration. They belong with specs, tickets, stories, and reviews rather than with plain terminals or file browsing.
