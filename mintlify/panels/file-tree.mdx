The **File Tree** panel lets you browse a workspace folder.

Use it to inspect files, open files in an external editor, or copy file paths.

Open it from the **File Tree** icon in the sidebar rail. Click a folder to expand it. Click a file to open it in a preview tab; double-click to keep the tab open.

## Workspace Picker

The panel uses a workspace picker to choose which folder the tree shows. Workspace selection affects which file paths are available from the panel.

## File Information

The File Tree can expose:

- path and file context
- file and folder hierarchy
- selected workspace context
- unavailable states when the host cannot load the file tree

## Open In Editor

The panel can open files in an external editor when Traycer can detect or use one. It can also copy file paths for manual use.
