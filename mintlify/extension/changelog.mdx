<Update label="v2.14.0">
* Epic Mode:
  * Introduced Epic Mode, a new workspace for spec-driven development where your engineering work lives as a structured system of Specs + Tickets.
  * Create, edit, and reference multiple Specs inside an Epic, then decompose directly into Tickets for execution.
* Workflows (guided, command-driven):
  * Epic Mode is driven through workflows, including a default Traycer Agile Workflow that guides users through requirement capture → planning → ticket breakdown.
  * Workflows are flexible and command-driven: you can branch, skip, or go deeper as needed, while Traycer suggests the next-best command to maintain momentum and keep the user experience effortless.
* Wireframes:
  * For UI changes, Specs include HTML wireframes so you can quickly see what the UI will look like.
  * To update a wireframe, just ask in the Epic chat and we'll revise it there.
* Execution from Epic:
  * Execute individual or multiple specs/tickets or the entire Epic at once.
  * Execution options from an Epic: Phases or Handoff to Agent-choose the right level of checkpointing based on the task's complexity and your preferences.
  * Each execution mode carries forward the Epic's context, so you don't have to keep rebuilding context from scratch.
* Streaming Q&As and Phases:
  * Questions and phases now stream in as they're generated, so you can start reviewing and acting immediately instead of waiting for the full set to load.
* Performance, stability, and bug fixes.
</Update>
